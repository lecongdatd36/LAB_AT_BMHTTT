## 2. Giới thiệu

Bài thực hành LAB 1 xây dựng chương trình mã hóa và giải mã bằng ngôn ngữ Java, sử dụng Java Swing để thiết kế giao diện, Apache NetBeans và Maven để quản lý dự án, kết hợp Microsoft SQL Server để lưu trữ lịch sử mã hóa.

## 3. Nội dung thực hiện

### Sáu thuật toán mã hóa cổ điển

1. **Caesar:** Mã hóa bằng phương pháp dịch chuyển ký tự.
2. **Vigenère:** Mã hóa sử dụng khóa chữ cái lặp lại.
3. **Rail Fence:** Mã hóa bằng phương pháp hoán vị zíc-zắc.
4. **Playfair:** Mã hóa theo từng cặp ký tự.
5. **Transposition:** Mã hóa bằng phương pháp hoán vị cột.
6. **Autokey:** Mã hóa bằng khóa tự động mở rộng.

### Chức năng nâng cao

- Xây dựng giao diện tổng hợp 6 thuật toán.
- Mã hóa và giải mã văn bản.
- Đọc và lưu bản mã bằng file `.txt`.
- Kết nối Microsoft SQL Server bằng JDBC.
- Lưu trữ và xem lịch sử mã hóa, giải mã.
- Thực hành phân tích và tấn công mật mã cổ điển.
