# LAB 2 – MÃ HÓA ĐỐI XỨNG HIỆN ĐẠI

## 1. Thông tin sinh viên

- **Họ và tên:** Lê Công Đạt
- **Lớp:** CNPM2
- **MSSV:** 1150080130
- **Học phần:** An toàn và Bảo mật thông tin

## 2. Giới thiệu

Bài thực hành Lab 2 xây dựng chương trình mã hóa và giải mã văn bản bằng Java Swing và Python Tkinter. Phần Java kết nối Microsoft SQL Server để quản lý tài khoản và lưu lịch sử thao tác.

## 3. Nội dung thực hiện

- **Java Swing (`LAB2_MaHoaHienDai`):** DES, TripleDES, AES-GCM, RC4, Twofish và AES-CTR.
- **Python Tkinter (`LAB2_Python`):** AES-256-CBC với chức năng tạo khóa, tạo IV, mã hóa, giải mã và lưu/mở bản mã.
- **Cơ sở dữ liệu:** [Script SQL Server](LAB2_MaHoaHienDai/lab2.sql).
